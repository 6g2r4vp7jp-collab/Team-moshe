## מוזיקה – רישיון
הפסקול והאפקטים הקוליים **הולחנו במיוחד לסרטון הזה** (סינתזה בקוד, `edit/soundtrack.py`). לא נעשה שימוש בדגימות, לופים או מוזיקה של צד שלישי.
**לכן אין רישיון של צד שלישי, ומותר שימוש מסחרי מלא ברשתות החברתיות ובפרסום** (אינסטגרם, טיקטוק, פייסבוק, יוטיוב, קידום ממומן). אין חשש לחסימת זכויות יוצרים (Content ID).
בנוסף נשמע סאונד מקורי מהצילומים שלכם עצמם (מכות בפדים, כפפות).

## בנייה מחדש
```
python3 edit/build_shots.py          # חיתוך, צבע, זום לכל שוט  -> work/shots
node    edit/render_overlay.js work/overlay.mov   # כתוביות וגרפיקה (שכבה שקופה)
python3 edit/soundtrack.py work/soundtrack.wav     # מוזיקה + סאונד
# ואז הרכבה סופית עם ffmpeg (ראו היסטוריית העבודה)
```
