# נתונים אמיתיים בלבד
כאן שמים קובצי Insights אמיתיים:
- `posts_*.csv`: פוסט בכל שורה (תבנית: `../insights_template.csv`, או ייצוא ישיר מ-Meta Business Suite)
- `weekly_kpis.csv`: מדדים שבועיים (`week_start,followers_total,new_followers,profile_visits,sponsor_inquiries,club_inquiries,club_signups`)

`sponsor_inquiries`, `club_inquiries` ו-`club_signups` מחושבים אוטומטית מה-CRM אם הם לא מופיעים כאן.
